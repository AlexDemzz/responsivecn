A drop-in replacement for the shadcn
[Dialog](https://ui.shadcn.com/docs/components/dialog): at 768px and up it
renders the Dialog unchanged; below, the same children render inside a
[Drawer](https://ui.shadcn.com/docs/components/drawer). The shared mechanism —
breakpoint, override prop, merge rules, controlling `open` — is documented once
in the [Introduction](/docs). Resize the window across 768px and reopen to see
the swap.

## Usage

```tsx
import {
  DialogDrawer,
  DialogDrawerClose,
  DialogDrawerContent,
  DialogDrawerDescription,
  DialogDrawerFooter,
  DialogDrawerHeader,
  DialogDrawerTitle,
  DialogDrawerTrigger,
} from "@/components/ui/dialog-drawer"
```

```tsx
<DialogDrawer>
  <DialogDrawerTrigger>Edit profile</DialogDrawerTrigger>
  <DialogDrawerContent>
    <DialogDrawerHeader>
      <DialogDrawerTitle>Edit profile</DialogDrawerTitle>
      <DialogDrawerDescription>Make changes to your profile here.</DialogDrawerDescription>
    </DialogDrawerHeader>
    <DialogDrawerFooter>
      <DialogDrawerClose>Cancel</DialogDrawerClose>
    </DialogDrawerFooter>
  </DialogDrawerContent>
</DialogDrawer>
```

## Composition

```txt
DialogDrawer
├── DialogDrawerTrigger
└── DialogDrawerContent
    ├── DialogDrawerHeader
    │   ├── DialogDrawerTitle
    │   └── DialogDrawerDescription
    └── DialogDrawerFooter
        └── DialogDrawerClose
```

## Overriding the Drawer

Everything inside `drawer={{}}` is the mobile Drawer's own API, typed 1:1 on
Vaul's own types (taken from its `.d.ts` — the Vaul docs are incomplete):
`snapPoints`, `direction`, `dismissible`, `handleOnly`, `autoFocus`, the
`onDrag`/`onRelease` callbacks, …

```tsx
<DialogDrawer drawer={{ snapPoints: [0.5, 1] }}>{/* … */}</DialogDrawer>
```

## Focus

Radix Dialog moves focus into the popup on open; the mobile Vaul drawer
suppresses it by default. Pass `drawer={{ autoFocus: true }}` so the drawer
takes focus too — without it the focused trigger ends up behind `aria-hidden`
and the console logs a focus-trap error.

## Not in v1

- **`showCloseButton` below the breakpoint**: the prop is desktop-only — a
  drawer dismisses by swipe. It keeps working at 768px and up.
