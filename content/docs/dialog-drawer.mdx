A drop-in replacement for the shadcn
[Dialog](https://ui.shadcn.com/docs/components/dialog): at 768px and up it renders
the Dialog unchanged; below, the same children render inside a
[Drawer](https://ui.shadcn.com/docs/components/drawer). The shared mechanism —
breakpoint, override prop, merge rules, controlling `open` — is documented once in
the [Introduction](/docs). Resize the window across 768px and reopen to see the
swap.

## Usage

```tsx
import {
  DialogDrawer,
  DialogDrawerClose,
  DialogDrawerContent,
  DialogDrawerDescription,
  DialogDrawerFooter,
  DialogDrawerHeader,
  DialogDrawerTitle,
  DialogDrawerTrigger,
} from "@/components/ui/dialog-drawer"
```

```tsx
<DialogDrawer>
  <DialogDrawerTrigger>Edit profile</DialogDrawerTrigger>
  <DialogDrawerContent>
    <DialogDrawerHeader>
      <DialogDrawerTitle>Edit profile</DialogDrawerTitle>
      <DialogDrawerDescription>Make changes to your profile here.</DialogDrawerDescription>
    </DialogDrawerHeader>
    <DialogDrawerFooter>
      <DialogDrawerClose>Cancel</DialogDrawerClose>
    </DialogDrawerFooter>
  </DialogDrawerContent>
</DialogDrawer>
```

## Composition

```txt
DialogDrawer
├── DialogDrawerTrigger
└── DialogDrawerContent
    ├── DialogDrawerHeader
    │   ├── DialogDrawerTitle
    │   └── DialogDrawerDescription
    └── DialogDrawerFooter
        └── DialogDrawerClose
```

## Overriding the Drawer

Everything inside `drawer={{}}` is your installed Drawer's own API, for
example snap points on Base UI (see the Radix notes below for Vaul):

```tsx
<DialogDrawer
  drawer={{
    snapPoints: [0.5, 1],
    defaultSnapPoint: 0.5,
    showSwipeHandle: true,
  }}
>
  {/* … */}
</DialogDrawer>
```

## `onOpenChange`

`onOpenChange` on the root is your Dialog's, unchanged, and it also fires
below 768px. Plain `onOpenChange={setOpen}` works. For a reason only the
Drawer has, such as a swipe, read it in the Drawer's own handler:

```tsx
<DialogDrawer
  onOpenChange={setOpen}
  drawer={{
    onOpenChange: (open, eventDetails) => {
      if (eventDetails.reason === "swipe") {
        // runs after the shared handler, below 768px only
      }
    },
  }}
>
  {/* … */}
</DialogDrawer>
```

## Not in v1

- **`handle` / `triggerId`**: `Dialog.Handle` and `Drawer.Handle` are distinct
  classes — a desktop handle cannot drive the mobile primitive, so detached
  triggers are dropped from this pair.
- **`showCloseButton` below the breakpoint**: the prop is desktop-only — a
  drawer dismisses by swipe. It keeps working at 768px and up.

## Radix notes

- `drawer={{}}` is typed on Vaul: `direction`, `dismissible`, `handleOnly`,
  `snapPoints`, the `onDrag`/`onRelease` callbacks, and so on.
- Radix Dialog moves focus into the popup on open; the Vaul drawer does not
  by default. Pass `drawer={{ autoFocus: true }}` so the drawer takes focus
  too. Without it the focused trigger ends up behind `aria-hidden` and the
  console logs a focus-trap error.
- Vaul, the drawer library under the Radix Drawer, is no longer maintained
  upstream. It still works; the Base UI Drawer is the maintained option.
