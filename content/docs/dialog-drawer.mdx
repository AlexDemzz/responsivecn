A drop-in replacement for the shadcn
[Dialog](https://ui.shadcn.com/docs/components/dialog): at 768px and up it
renders the Dialog unchanged; below, the same children render inside a
[Drawer](https://ui.shadcn.com/docs/components/drawer). The shared mechanism —
breakpoint, override prop, merge rules, state loss — is documented once in the
[Introduction](/docs).

## Overriding the Drawer side

Everything inside `drawer={{}}` is the Drawer wrapper's own API — for example,
opening the mobile drawer on snap points:

<Tabs groupId="base" persist items={["Base UI", "Radix"]}>

<Tab>

```tsx
<DialogDrawer
  drawer={{
    snapPoints: [0.5, 1],
    defaultSnapPoint: 0.5,
    showSwipeHandle: true,
  }}
>
  {/* … */}
</DialogDrawer>
```

</Tab>

<Tab>

```tsx
<DialogDrawer drawer={{ snapPoints: [0.5, 1] }}>{/* … */}</DialogDrawer>
```

On Radix, `drawer={{}}` is typed 1:1 on Vaul's API, taken from its `.d.ts`
(the Vaul docs are incomplete): `snapPoints`, `direction`, `dismissible`,
`handleOnly`, `autoFocus`, the `onDrag`/`onRelease` callbacks, …

</Tab>

</Tabs>

## `onOpenChange`

<Tabs groupId="base" persist items={["Base UI", "Radix"]}>

<Tab>

`onOpenChange` is typed as the union of both primitives'
`ChangeEventDetails`, so `reason` narrows without a cast — including
Drawer-only reasons:

```tsx
<DialogDrawer
  onOpenChange={(open, eventDetails) => {
    if (eventDetails.reason === "swipe") {
      // Drawer-only close reason — narrowed, no cast
    }
    if (eventDetails.reason === "escape-key") {
      eventDetails.cancel()
    }
  }}
>
  {/* … */}
</DialogDrawer>
```

Plain `onOpenChange={setOpen}` still works: callbacks may declare fewer
parameters.

</Tab>

<Tab>

`onOpenChange` is `(open: boolean) => void` on both sides — Radix has no
`ChangeEventDetails`, so there is no `eventDetails`, no `reason` and no
`cancel()`. Cross-base parity is prop-name parity, not prop-type parity.

```tsx
<DialogDrawer open={open} onOpenChange={setOpen}>
  {/* … */}
</DialogDrawer>
```

</Tab>

</Tabs>

## Not in v1

- **`handle` / `triggerId`** (Base UI): `Dialog.Handle` and `Drawer.Handle`
  are distinct classes — a desktop handle cannot drive the mobile primitive,
  so detached triggers are dropped from this pair.
- **`showCloseButton` below the breakpoint**: the prop is desktop-only — a
  drawer dismisses by swipe. It keeps working at 768px and up.

## Radix notes

<Callout type="warn" title="Radix notes">

- **Vaul is unmaintained.** It is the mobile side of three of the four Radix
  pairs, this one included — choose the `-radix` variants knowingly.
- `onOpenChange` is `(open: boolean) => void` — no `eventDetails`, no
  `reason`, no `cancel()`.
- **Focus**: Radix Dialog moves focus into the popup on open; Vaul suppresses
  it by default. Pass `drawer={{ autoFocus: true }}` — without it the focused
  trigger ends up behind `aria-hidden` and the console logs a
  focus-trap/aria-hidden error.
- **Non-modal drawers do not dismiss on outside press.** A non-modal Vaul
  drawer stays open when you click outside it, unlike the desktop Dialog.

</Callout>

## Component docs

The underlying components are documented upstream, not here:

- **Base UI pair**: shadcn
  [Dialog](https://ui.shadcn.com/docs/components/dialog) and
